# 제주 어디가잰? (2단계)

제주 역사문화 데이터로 만든 답사 지도입니다. 1단계(파일 데이터)를 **API 호출 구조**로 바꾼 버전입니다.

## 화면 구성
화면은 한 페이지(`index.html`)이고, 아래 영역으로 나뉩니다.

| 영역 | 보여 주는 것 |
|---|---|
| 상단 헤더 | 사이트 이름, 명소·추천 코스 개수, 데이터 상태(🟢 API 연결됨 / 🟠 연습 모드) |
| 왼쪽 패널 · 추천 코스 탭 | 테마별 추천 코스 11개. 코스를 열면 방문 순서, 근처 맛집, "내 코스에 담기" |
| 왼쪽 패널 · 장소 찾기 탭 | 검색창, 분류 칩, 장소 카드(찜·자세히) |
| 왼쪽 패널 · 내 코스 탭 | 찜한 장소·맛집, 순서 변경·삭제, 직선거리 합계 |
| 지도 | 이모지 핀 120개, 코스 선, 주변 맛집, 추천 코스 바로가기 칩, 범례, 맛집 보기 버튼 |
| 상세 패널(지도 오른쪽) | 사진, 주소, 키워드, 초록·내용, 주변 맛집, 길찾기 |

## 데이터가 들어오는 길
```
브라우저 ──▶ /api/culture (Vercel 서버 함수) ──▶ 공공데이터포털 API 2개
   ▲                         │  (일반정보 + 위치정보를 고유번호로 합침)
   └──── 실패하면 ◀──────────┘  파일 데이터(index.html 안에 포함)로 "연습 모드" 표시
```
- API 키는 브라우저로 나가지 않고 서버 함수(`api/culture.js`)에서만 읽습니다.
- 데이터를 기다리는 동안 "불러오는 중…" 화면이 나옵니다.
- 키가 없거나 API가 실패하거나 파일(`file://`)로 열면 1단계 데이터로 보여 주고 헤더에 🟠 **연습 모드**라고 표시합니다.
- 맛집(향토음식업소 CSV + OpenStreetMap)과 추천 코스, 사진은 파일 데이터입니다.

## 환경변수 (Vercel에도 같은 이름으로 등록)
`.env.example`을 복사해 `.env.local`을 만들고 값을 채웁니다. `.env.local`은 `.gitignore`에 들어 있어 GitHub에 올라가지 않습니다.

| 이름 | 내용 |
|---|---|
| `JEJU_CULTURE_INFO_KEY` | 제주역사문화일반정보 API 키 |
| `JEJU_CULTURE_LOCATION_KEY` | 제주역사문화위치정보 API 키 |

API 요청 주소(odcloud)는 키가 아니라 공개된 값이라 `api/culture.js`에 들어 있습니다. 명세: [일반정보](https://infuser.odcloud.kr/oas/docs?namespace=15109587/v1) · [위치정보](https://infuser.odcloud.kr/oas/docs?namespace=15109570/v1)

## 사용자 관점 개선점 (10가지)
처음 쓰는 사람의 눈으로 살펴본 개선점입니다. (고치기 전에 정리한 목록)

1. **첫 화면 안내가 없다** — 무엇을 눌러야 하는지(추천 코스 → 핀 → 찜 → 내 코스) 설명이 없다. 처음 방문 시 3단계 안내를 보여 준다.
2. **"자세히"를 누르면 화면 전체가 아래로 내려간다** — 지도에서 눈을 떼야 한다. 지도 옆에서 열리는 상세 패널(또는 팝업)로 바꾼다.
3. **내 코스 순서를 직접 맞춰야 한다** — "가까운 순으로 자동 정렬" 버튼을 넣고, 거리뿐 아니라 이동 시간(차량·도보 대략)도 보여 준다.
4. **코스를 저장·공유할 수 없다** — 브라우저에만 저장되고 이름도 못 붙인다. 코스 이름 짓기, 링크 공유, 인쇄(이미지·PDF)를 지원한다.
5. **길찾기로 이어지지 않는다** — 장소·맛집에서 카카오맵/네이버 지도 길찾기로 바로 연결한다.
6. **맛집 정보가 부족하고 믿기 어렵다** — OpenStreetMap 음식점은 종류·영업 여부가 비어 있다. 종류 필터(한식·해산물 등)와 "최신 영업 여부는 확인 필요" 안내를 붙이고, 2단계 API로 정확한 정보를 보강한다.
7. **사진이 5곳뿐이라 대부분 이모지다** — 사진이 없는 곳은 비어 보인다. 사진 API 연동과 "사진 준비 중" 표시를 넣는다.
8. **검색이 단순하다** — 오타·초성 검색이 안 되고, "내 주변"이나 "지금 지도에 보이는 곳만 보기"가 없다.
9. **작은 화면·접근성 점검이 부족하다** — 휴대폰 배치, 이모지만으로 구분되는 분류, 키보드 조작, 색 대비를 점검하고 고친다.
10. **상태 안내가 약하다** — "연습 모드"가 무슨 뜻인지 설명이 없고, 지도 타일이 안 뜰 때 알림이 없다. 설명 문구와 오류 안내를 넣는다.

## 고친 것 · 추가한 것
### API 연동 (2단계 필수)
- 공공데이터포털 API 2개(일반정보·위치정보)를 서버 함수 `api/culture.js`가 호출해 고유번호로 합친다. 키는 서버에서만 읽는다.
- 데이터를 기다리는 동안 "불러오는 중…" 화면, 실패하면 1단계 파일 데이터로 보여 주고 헤더에 🟠 연습 모드를 표시한다.

### 개선점에서 고친 것
- **1번 첫 화면 안내**: 처음 방문 시 사용법 3단계 안내가 뜬다. "다시 보지 않기"를 고를 수 있고, 헤더의 ❔ 사용법 버튼으로 다시 볼 수 있다.
- **2번 상세 설명 위치**: "자세히"를 누르면 화면이 아래로 내려가지 않고, 지도 오른쪽에 상세 패널이 열린다. 핀은 패널에 가리지 않게 왼쪽으로 옮겨 보여 주고, ✕ 버튼·Esc·"닫기"로 닫는다.
- **3번 내 코스 정렬·이동 시간**: "🧭 가까운 순으로 정렬"(첫 장소는 그대로, 최근접 이웃 + 2-opt)과 코스·구간별 이동 시간(직선거리 × 1.3, 차 35km/h·도보 4km/h 추정)을 보여 준다.
- **5번 길찾기 연결**: 장소·맛집 말풍선, 상세 패널, 맛집 목록, 내 코스 단계에서 카카오맵·구글맵 길찾기를 열 수 있고, 내 코스 전체는 구글맵 경로(최대 10곳)로 열 수 있다.

### 1단계에서 이어 온 기능
추천 코스 11개(동선 최단 순서), 향토 맛집 51곳 + OpenStreetMap 음식점 5천여 곳, 이모지 핀, 사진 5장(출처 표시), 지도 제주도 영역 제한.

### 아직 하지 않은 개선점
4번(코스 저장·공유), 6번(맛집 정보 보강), 7번(사진), 8번(검색 강화), 9번(작은 화면·접근성), 10번(상태 안내).
